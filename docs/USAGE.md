# 健力宝使用说明

日常入口：[打开健力宝](https://jianlibao-training-raitox.netlify.app/)。推荐先添加到主屏幕，再固定使用同一入口。

## 安装与更新

| 平台 | 操作 |
| --- | --- |
| iPhone / iPad | Safari → 分享 → 添加到主屏幕。 |
| 安卓 | Chrome 等浏览器 → 菜单 → 安装应用 / 添加到主屏幕；应用内“我 → 安装到手机”有对应引导。 |
| 电脑 | 浏览器直接使用；支持的浏览器可通过地址栏安装图标建立独立窗口。 |

保存训练后，在“我 → 应用与离线”检查更新；关闭所有旧健力宝窗口后重新打开。不要通过清除网站数据更新。

## 训练记录

1. “今天”开始训练，或“计划”选择模板；已有草稿时先继续或处理草稿。
2. 填写实际重量、次数或时长；`＋ / −`调整数值，不会自动完成本组。
3. 完成每组后点完成，可撤销、跳过或更改组类型；需要时记录 RPE 和备注。
4. 使用休息计时；声音和震动可关闭。网页锁屏或后台提醒受手机系统限制。
5. 结束后进入回顾并“保存训练”。只有归档后才出现在历史和统计中。

重量记录包含杠的总外部负重，双哑铃按两只合计。次数、时长和容量分别统计；估算1RM不代表已实际完成该重量。

## 动作讲解

在“动作”按名称、肌群或器械查找，打开卡片可切换简洁讲解、详细讲解和个人表现。三帧 SVG 与中文要点保留；部分动作还有补充图片/视频，作者及许可就在素材旁边。

视频默认静音、按需加载。需要离线时点“保存示范供离线使用”并等待完整保存；仅播放过不等于完整缓存。素材异常可以重新加载，仍可继续看原 SVG 和文字。

## 历史、统计与身体数据

“进步”有训练历史、统计总览和动作追踪：查日历、看逐组结果、修正、补记、复练，也能导出 CSV 明细。正式容量排除热身、跳过和未完成组。

“我 → 记录身体数据”填写日期、体重、体脂率、围度和备注，每天一条，可以编辑；没有测量的项目留空，不填0代替。

## 离线、备份与换机

- “我 → 应用与离线”显示离线启动状态。图解库和图片/视频示范需要分别准备。
- 定期导出完整 JSON 并保留多份；CSV 只用于查看明细，无法代替 JSON 恢复。
- 换入口前先在原入口导出，在新入口导入，阅读预览并处理冲突；保留旧文件和旧入口数据。
- 本地数据属于当前浏览器及当前站点。隐私模式结束、手动清理或系统回收可能移除数据。

## 可选加密云同步

1. 第一台设备在“我 → 云同步”创建同步，保存密钥文件，再确认开启。
2. 其他设备连接已有同步，使用同一个完整密钥。
3. 联网、回到前台或点“立即同步”时同步；冲突按真实记录逐条选择。

归档训练、身体记录、动作和模板参与同步；进行中的训练与设备偏好留在本机。密钥不能从普通备份恢复，请单独保存，不发给他人。

固定网页版带有已部署的同步后端；下载的静态 ZIP 或本地 Vite 本身不提供该后端。自托管请部署自己的函数服务，不能把其他人的同步密钥放进源码。

## 常见问题

| 情况 | 处理 |
| --- | --- |
| 新入口没有旧训练 | 回原网址/原浏览器，用 JSON 或同一同步密钥迁移。 |
| 训练没有出现在历史 | 看是否仍在草稿或待回顾；完成回顾并保存训练。 |
| 离线时示范打不开 | 联网检查该动作是否已完整保存，重新保存未完成素材。 |
| 新版本没出现 | 保存后关闭全部旧窗口再打开，不要清网站数据。 |
| IPA 无法直接安装 | 当前 IPA 未签名；手机日常使用请选择 PWA。 |
